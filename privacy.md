# Privacy Policy — Imperial Orchestra Backup

**Last updated:** November 11, 2026

## Overview

Imperial Orchestra Backup is a private backup automation tool used exclusively by its owner to store encrypted database backups in Google Drive.

## Google Drive Access

The application uses the Google Drive API to upload, list, and delete backup archives in the owner's Google Drive account.

The application does not access unrelated files for advertising, profiling, or analytics.

## Data Storage and Security

Database backups are encrypted before being uploaded to Google Drive.

Access credentials are stored securely as GitHub Actions secrets and are not published in source code.

## Data Sharing

The application does not sell or share Google user data with third parties for advertising or marketing.

## Data Retention

Backup files are retained according to the configured backup retention policy and may be deleted by the account owner at any time.

## Contact

For privacy inquiries, contact the application owner through the associated GitHub account.
